# Edu AI Studio 교수지원 플랫폼 1.0

> 대학 교수자를 위한 AI 기반 수업설계·평가·학습자료 제작 시범 플랫폼

Edu AI Studio는 대학 교수가 과목 정보를 입력한 뒤, 16주 수업계획·퀴즈·평가 루브릭·과제 피드백·학생용 AI 튜터 자료를
직접 만들고 브라우저에 저장할 수 있는 **교육용 시범 플랫폼**입니다. 외부 데이터베이스와 실제 AI API를 사용하지
않으며, 모든 데이터는 사용자의 브라우저(localStorage)에만 저장됩니다.

## 기술 스택

- React 18 + TypeScript
- Vite 6
- Tailwind CSS 3
- lucide-react (아이콘)
- localStorage (데이터 저장, 외부 DB 미사용)

## 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 개발 서버 실행 (기본 포트 5173)
npm run dev

# 3. 프로덕션 빌드
npm run build

# 4. 빌드 결과 미리보기
npm run preview

# 5. 린트 검사
npm run lint
```

빌드 결과물은 `dist/` 폴더에 생성되며, 정적 파일 호스팅 서비스(Netlify, Vercel, GitHub Pages 등)에 그대로 배포할 수
있습니다. 별도의 백엔드 서버나 데이터베이스가 필요하지 않습니다.

## 메뉴 구성

1. **홈** — 이어서 작업하기(진행률 포함) 또는 새 과목 시작하기, 예시 과목 둘러보기
2. **과목 설정** — [1.기본 정보] 전공·과목명·학년·학점·수업 형태 / [2.세부 내용] 교과목 개요·학습 목표·평가 방법·교재
3. **16주 수업설계** — 주차별 주제·학습목표·핵심개념·교수/학생 활동·AI 활용 방법·과제·평가 방법 (아코디언 편집)
4. **퀴즈 생성기** — [1단계 입력] 유형·난이도·문항 수로 문항 생성 / [2단계 결과] 문항별 문제·정답·해설 편집
5. **루브릭 생성기** — [1단계 입력] 과제명·평가 목적 / [2단계 결과] 평가 영역별 배점·4단계 성취수준·총점 자동 계산
6. **과제 피드백** — 학생 A/B/C 답안을 탭으로 전환하며 강점·개선점·수정 방향 검토 → 종합 의견 → 교수자 최종 검토
7. **AI 튜터** — 전공·질문 선택(입력) → 시범 답변·핵심 개념·추가 학습 질문 확인(결과), 실제 AI API 미사용
8. **설정 및 사용 안내** — 사용 방법, 자료 보관 위치, 파일로 저장/불러오기, 전체 초기화, 유의사항, 소개

## 데이터 저장 방식

- 모든 입력값은 브라우저의 `localStorage`에 자동 저장되며, 새로고침 후에도 유지됩니다.
- 설정 메뉴의 **전체 자료 파일로 저장** 버튼으로 내려받은 파일을 **저장한 파일 불러오기** 버튼으로 다시 불러올 수 있습니다.
- 전체 초기화 시 확인창을 거치며, 초기화 후에는 되돌릴 수 없습니다.
- 홈 화면에서 **서비스경영**, **기본간호학** 두 가지 예시 과목의 16주 수업설계·퀴즈·루브릭·피드백·AI 튜터 자료를
  한 번에 불러올 수 있습니다.

## 프로젝트 구조

```
src/
├── components/
│   ├── common/       # 공통 UI 컴포넌트 (버튼, 폼 필드, 배지, 토스트, 빈 화면, 모달 등)
│   └── layout/        # 사이드바, 모바일 메뉴, 상단바, 전체 레이아웃
├── context/            # 프로젝트 데이터 전역 상태 (localStorage 연동)
├── data/               # 예시 과목 데이터, 기본 틀 생성기, AI 튜터 시드 데이터
├── hooks/              # useLocalStorage 등 커스텀 훅
├── pages/              # 8개 메뉴별 페이지 컴포넌트
├── types/              # TypeScript 타입 정의
└── utils/              # localStorage 저장/복원, 파일 다운로드, 클립보드 복사 등 유틸
```

`components/common/Tabs.tsx`는 과목 설정(기본 정보/세부 내용)과 과제 피드백(학생 A/B/C)에서
쓰는 공통 탭 컴포넌트입니다.

## 유의사항 (중요)

- 본 플랫폼은 **교육용 시범(프로토타입) 버전**이며 실제 서비스 운영을 위한 것이 아닙니다.
- 로그인 기능이 없으며, 데이터는 사용 중인 브라우저에만 저장됩니다. 다른 기기·브라우저와 공유되지 않습니다.
- **학생 이름, 학번, 연락처 등 실제 개인정보를 입력하지 마세요.** 과제 피드백의 학생 답안은 모두 가상 예시입니다.
- 첫 버전에서는 **실제 AI API를 호출하지 않으며**, "AI 활용"·"AI 튜터" 관련 결과는 모두 시범을 위한 예시 응답입니다.
  실제 강의에 활용하기 전 반드시 교수자가 검토·수정해야 합니다.

## 완성된 기능

- 8개 메뉴 전체 구현 및 정상 동작 (홈, 과목 설정, 16주 수업설계, 퀴즈 생성기, 루브릭 생성기, 과제 피드백, AI 튜터, 설정)
- 서비스경영·기본간호학 두 예시 과목의 전체 16주 수업설계, 퀴즈, 루브릭, 과제 피드백, AI 튜터 예시 데이터
- 16주 수업설계: 자동 예시 생성, 행별(주차별) 수정, 저장, 복사, 파일로 저장(JSON), 인쇄, 전체 초기화
- 퀴즈 생성기: 입력(유형·난이도·문항 수)과 결과(문항 목록)를 단계로 구분, 문항별 수정, 세트 관리, 저장, 복사
- 루브릭 생성기: 평가 영역 추가/삭제, 4단계 성취수준, 총점 자동 계산, 표 형태 출력(모바일에서는 카드형으로 전환)
- 과제 피드백: 학생 A/B/C 답안 탭 전환, 강점/개선점/수정방향/종합의견/교수자 최종 검토, 개인정보 미사용 안내
- AI 튜터: 전공별 질문 예시, 예시 답변 토글, 핵심 개념, 추가 학습 질문, 커스텀 질문 추가, 시범 응답 안내
- 설정 및 안내: 사용 방법, 자료 보관 방식 설명, 파일로 저장/불러오기, 전체 초기화(확인창 포함), 유의사항, 소개
- localStorage 기반 자동 저장 및 새로고침 후 복원, 저장 실패 시 안내 메시지 표시
- 저장 완료 토스트 알림, 빈 화면 상태(EmptyState), 로딩 스피너, 오류 경계(ErrorBoundary)
- 데스크톱 사이드바 / 모바일 접이식 메뉴 반응형 레이아웃, 모바일에서는 표 대신 카드형 레이아웃
- 모든 화면 상단 '교육용 시범 플랫폼' 배지 표시
- 주요 동작(저장 등)과 보조 동작(복사·인쇄·초기화 등)의 버튼 위계 구분
- 접근성: 시맨틱 라벨, aria 속성, 키보드 포커스 스타일, 확인 모달 포커스 관리
- `npm run build`, `npm run lint` 정상 통과 (TypeScript 오류 없음)

## 미완성/의도적 범위 제외 기능

- 실제 외부 AI API 연동 (요구사항에 따라 1차 버전에서 의도적으로 제외, 모든 AI 관련 기능은 시범 응답)
- 로그인/사용자 인증 (요구사항에 따라 의도적으로 제외)
- 외부 데이터베이스 연동 (요구사항에 따라 의도적으로 제외, localStorage만 사용)
- 여러 교수자 간 데이터 공유·협업 기능 (단일 브라우저 저장 구조의 특성상 미지원)
