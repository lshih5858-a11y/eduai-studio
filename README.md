# AI 주식 투자 학습 코치

주식 투자의 기본 개념, 재무지표, 리스크 관리, 포트폴리오 구성, 모의투자 사고방식을
쉽게 배울 수 있도록 만든 **교육용 모의투자 학습 웹앱**입니다. 대학 특강이나
교육 현장에서 바로 시연할 수 있도록 설계되었습니다.

> ⚠ **본 프로그램은 투자 권유가 아니라 주식 공부를 위한 교육용 시뮬레이션입니다.**
> 모든 종목, 주가, 수익률, 차트 데이터는 실제 시장과 무관한 가상 데이터입니다.
> 실제 종목 추천, 매수·매도 추천, 수익 보장을 하지 않으며, 외부 주식/증권사/실시간
> 시세 API를 전혀 사용하지 않습니다. 개인정보와 투자정보는 서버에 저장되지 않고
> 브라우저 내에서만 계산됩니다.

## 프로젝트 소개

- 초보자가 PER, PBR, ROE 같은 재무지표와 분산투자, 리스크 관리 개념을 학습용
  가상 종목과 가상 차트로 연습해볼 수 있습니다.
- 투자 성향 진단, 모의 포트폴리오 시뮬레이터, 투자 판단 체크리스트, 초보자 퀴즈,
  키워드 기반 AI 학습 코치, 월간 학습 리포트 생성까지 하나의 흐름으로 제공합니다.
- 모든 데이터는 클라이언트(브라우저) 상태로만 관리되며, 외부 API 호출이나 서버
  저장이 없습니다.

## 기술 스택

- React 18 + Vite + TypeScript
- Tailwind CSS
- Recharts (가상 주가 차트)

## 설치 방법

```bash

```

## 주요 기능

1. **메인 대시보드** — 프로그램 소개, 오늘의 학습 목표, 학습 현황 요약 카드
   (투자 성향, 포트폴리오 위험도, 학습 완료율, 체크리스트 점수, 퀴즈 점수)
2. **투자 성향 진단** — 5개 질문으로 안정형·균형형·적극형 성향을 분석하고,
   학습 방향과 리스크 관리 조언을 교육용으로 제공
3. **주식 기초 학습 카드** — 주식, 시가총액, PER, PBR, ROE, EPS, 배당수익률,
   변동성, 분산투자, 장기투자, 손절, 리밸런싱 12개 개념 카드 (더 알아보기 확장)
4. **가상 종목 학습 · 주가 차트** — 가상 종목 5개(Alpha전자, BioNext, GreenEnergy,
   DailyDividend, KoreaETF50)의 재무지표 해석과 12개월 가상 주가 흐름 차트
5. **모의 포트폴리오 시뮬레이터** — 가상 투자금 1,000만 원을 자산군별로 배분하고
   위험도·안정성·성장 가능성·현금 대응력·배당 기대 수준·분산투자 점수 학습
6. **투자 판단 체크리스트** — 투자 전 점검할 10개 항목과 단계별 학습 피드백
7. **초보자 주식 퀴즈** — PER/PBR/ROE/분산투자/배당수익률/변동성/장기투자 7문항
8. **AI 주식 학습 코치** — 외부 AI API 없이 키워드 기반 규칙으로 답변하는
   학습 챗봇
9. **월간 학습 리포트** — 진단 결과, 포트폴리오, 체크리스트, 퀴즈 점수를 바탕으로
   자동 생성되는 복사 가능한 텍스트 리포트
10. **교수자 시연 포인트** — 교육 현장에서 활용할 수 있는 AI 활용 포인트 안내

## 교육용 면책 안내

- 본 프로그램에서 제공하는 모든 종목명, 주가, 재무지표, 수익률, 차트 데이터는
  **실제 시장과 무관한 가상 데이터**이며, 특정 기업을 지칭하지 않습니다.
- 본 프로그램은 **투자 권유, 매수·매도 추천, 수익 보장을 하지 않으며**, 오직
  주식 투자 개념 학습을 위한 시뮬레이션 도구입니다.
- 실제 투자 판단은 반드시 본인의 책임 하에 충분한 검토를 거쳐 이루어져야 합니다.
